# 🎮 Jogo da Velha Avançado (Tic-Tac-Toe)

Uma versão evoluída, interativa e altamente configurável do clássico Jogo da Velha, desenvolvida a partir da refatoração do tutorial oficial do React. O projeto aplica arquitetura moderna de Front-End, princípios de Clean Code, estilização modular com CSS Modules e metodologia BEM, além de integração com Bootstrap para estrutura responsiva.

---

## 🎯 Objetivo do Projeto

O objetivo principal é refatorar e expandir o código base disponibilizado pela documentação do React, transformando uma aplicação simples em um jogo dinâmico e tecnológico.

### 🌟 Diferenciais e Funcionalidades
- **Tamanhos Variáveis de Tabuleiro:** Escolha entre **3x3** (Normal), **4x4** (Médio), **5x5** e **6x6** (Avançado).
- **Modos de Jogo:**
  - **Jogador vs Jogador (PvP):** Personalização de nomes dos participantes antes de iniciar.
  - **Jogador vs Inteligência Artificial (PvE):** Desafie o computador em partidas dinâmicas.
- **Placar Interativo e Dinâmico:**
  - Exibição de vitórias, derrotas e empates no topo da tela.
  - Reconhecimento automático com o nome do jogador vitorioso.
  - Destaque para sequências acumulativas de vitória (ex: *"Usuário 2x"*).
- **Controle Flexível de Partida:**
  - **Reiniciar Placar:** Zeramento da pontuação mantendo os jogadores e o formato do tabuleiro.
  - **Reiniciar Tudo:** Retorno à tela inicial de configurações para novas escolhas de modo e nomes.

---

## 🛠️ Tecnologias e Linguagens Utilizadas

- **Linguagens Base:**
  - **HTML5:** Estruturação semântica e boas práticas de Acessibilidade (atributos ARIA).
  - **CSS3:** Variáveis CSS, CSS Modules e Metodologia BEM para isolamento de estilos.
  - **JavaScript (ES6+) / JSX:** Lógica da aplicação, manipulação imutável de estado e regras do jogo.
- **Framework & Ferramentas:**
  - **React:** Componentização, Hooks (`useState`), Elevação de Estado e Composição.
  - **Vite:** Build Tool rápida e servidor de desenvolvimento de alta performance.
  - **Bootstrap:** Layout de Grid e estrutura responsiva.
